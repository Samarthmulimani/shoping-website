\# Shopping Website



A simple shopping website developed as a mini project using HTML, CSS, JavaScript, and other web technologies.



\## Features



\- User-friendly shopping interface

\- Product listing

\- Product details

\- Add to cart

\- Responsive design

\- Simple and clean UI



\## Technologies Used



\- HTML

\- CSS

\- JavaScript



\## How to Run



1\. Download or clone this repository.

2\. Open the project folder.

3\. Open `index.html` in a web browser.
